# Ibrahim Suhail — Professional Links

Free static professional links page for GitHub Pages.

## Publish
1. Create a PUBLIC GitHub repository named `<your-github-username>.github.io`.
2. Upload all files/folders from this package to the repository root.
3. Open repository Settings → Pages.
4. Under Build and deployment choose `Deploy from a branch`.
5. Choose branch `main` and folder `/(root)`, then Save.
6. Your site will be available at `https://<your-github-username>.github.io/`.
